# Kelicap Components

[![Kelicap Web Components](../assets/branding/kelicap_1_banner.jpeg)](https://github.com/dukefirehawk/kelicap_components)

[![License](https://img.shields.io/github/license/dukefirehawk/kelicap_components)](https://github.com/dukefirehawk/kelicap_components/LICENSE)
[![melos](https://img.shields.io/badge/maintained%20with-melos-f700ff.svg?style=flat-square)](https://github.com/invertase/melos)

A collection of web components library for Kelicap web framework build with Material Design 2 guidelines.

## Getting Started

### Installation

```yaml
dependencies:
  kelicap_components: ^1.0.0
```
