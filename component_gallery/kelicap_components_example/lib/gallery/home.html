Material design components for Kelicap

Material Design 2 web components for the Kelicap framework.

Kelicap Components is a library of buttons, inputs, menus, dialogs, date pickers, lists and more, built on package:web. It is a fork of AngularDart Components, modernized for Dart 3. This gallery shows each component, its demos and its documentation.
